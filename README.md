フィンランド発祥の人気投擲スポーツ **「モルック (Mölkky)」** をブラウザで本格体験できる3Dウェブゲームです。  
リアルな3D剛体物理演算（Rapier3D）と、直感的なパチンコ式投擲操作で、誰でも手軽に白熱のゲームを楽しめます！

---

## 🎮 主な特徴

- **リアルな3D物理シミュレーション**  
  木製モルック棒とスキットルの衝突・反発・転がりを、WebAssemblyベースの高速物理エンジン **Rapier3D** で高精度に再現。
- **直感的なパチンコ式（スリングショット）投擲**  
  画面を手前に引っ張って離すだけ！引く距離と角度でパワーと方向を自在にコントロール。
- **放物線エイム予測ガイド**  
  投げ出し前に着弾予測サークルと弾道ラインが表示され、初心者でも狙い通りの投擲が可能。
- **最大4人のマルチプレイ＆CPU対戦**  
  人間同士の対戦はもちろん、AI CPUとの対戦にも対応。
- **多彩なパーティーギミックモード**  
  公式ルール準拠の通常モードに加え、爆弾やUFOが飛び交うカオスな特別モードを搭載！

## 🕹️ ゲームモード

| モード | アイコン | 説明 |
| :--- | :---: | :--- |
| **通常モード** | 🎯 | 公式モルックルールに完全準拠した本格競技モード。 |
| **TNT爆弾モード** | 💣 | フィールドにランダムで爆弾が出現！当てるとスキットルが爆風で大四散！ |
| **UFOアブダクション** | 🛸 | ターン経過でUFOが飛来！離れたスキットルを光線で吸い上げ、別の場所へ移送ドロップ！ |
| **全載せカオスモード** | 💥 | 爆弾とUFOが同時に出現するハチャメチャパーティーモード！ |

> [!TIP]
> **🛸 長期戦の救済システム（通常モードでのUFO介入）**  
> 通常モードであっても、試合が膠着して **50ターン** を超えた場合、救済措置としてUFOが飛来します！  
> 遠くへ飛ばされすぎて狙えなくなったスキットルをビームで自動回収し、手前の狙いやすい安全な位置へ移送・再配置してゲームの停滞を解消してくれます。

## 📖 モルックの基本ルール

1. **目的**  
   モルック棒を投げてスキットル（ピン）を倒し、**ちょうど 50点** を獲得したプレイヤーの勝利！
2. **得点計算**  
   - **1本だけ倒した場合**: 倒れたスキットルに書かれた**数字**が得点（例: 12番なら12点）
   - **複数本倒した場合**: 倒れた**本数**が得点（例: 3本倒したら3点）
3. **バースト（50点オーバー）**  
   50点を超えてしまった場合、ペナルティとして**25点にリセット**されてゲーム続行。
4. **連続ミス**  
   3回連続で1本も倒せなかった（ファウル）プレイヤーは**失格**となります。
5. **スキットルの立て直し**  
   倒れたスキットルは、**倒れたその位置で引き起こして**ゲームを再開します（回を重ねるごとに散らばり、戦略性が向上します）。

## 🎯 操作方法

- **投擲準備**: 画面（またはモルック棒の手前）をクリック / タップして長押し
- **エイム調整**: 下方向へドラッグして引く（引く長さ＝投擲パワー、角度＝投擲方向）
- **投擲**: 指・マウスを離すとモルック棒が放たれます

## 🚀 ローカル開発環境のセットアップ

```bash

git clone https://github.com/mana2p/molkky.git
cd molkky

# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (Vite)
npm run dev

# プロダクションビルド
npm run build
```
